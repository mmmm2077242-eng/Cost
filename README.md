# متابعة تكاليف المشاريع

تطبيق ويب بسيط (ملف واحد) لمتابعة تكاليف العمالة وصافي الربح لأكثر من مشروع في نفس الوقت. يعمل بالعربية من اليمين لليسار، ومصمم للموبايل أولاً.

## المميزات

- **أكثر من مشروع:** لكل مشروع سجله اليومي وأسعاره وإيراداته، مع شاشة «نظرة عامة» تجمع كل المشاريع.
- **خانات ثابتة:** أسعار تُحسب تلقائياً (تكلفة العامل، رئيس الوردية، النقل، أو أي خانة تضيفها). كل خانة إما «لكل عامل» أو «لكل يوم».
- **خانات متغيرة:** خانات تحددها بنفسك وتدخل قيمتها كل يوم، ونوعها مبلغ أو رقم أو نص.
- **تكاليف إضافية:** بنود حرة (بيان وسعر) داخل أي يوم.
- **الإيراد وصافي الربح:** سجّل التوتال النهائي أو الدفعات، ويُطرح من التكاليف لإظهار صافي الربح وهامشه.
- **ملخص شهري:** نسب كل بند من الإجمالي، وزر لنسخ الملخص ومشاركته.
- **الوضع الليلي** تلقائياً حسب إعدادات الجهاز.

## النشر على GitHub Pages

1. أنشئ مستودعاً جديداً على GitHub.
2. ارفع الملفين `index.html` و`README.md` (من زر **Add file ← Upload files**).
3. من **Settings ← Pages** اختر **Deploy from a branch**، ثم الفرع `main` والمجلد `/ (root)`، واضغط **Save**.
4. بعد دقيقة يظهر الرابط بالشكل `https://USERNAME.github.io/REPO-NAME/`.

## ملاحظات

- البيانات تُحفظ داخل متصفح الجهاز نفسه (`localStorage`)، فلا تظهر على جهاز أو متصفح آخر، وتضيع إذا مُسحت بيانات الموقع من المتصفح.
- لا يحتاج التطبيق إلى خادم ولا مكتبات خارجية.
